2. **0/200 is not "never fails."** The 95% upper bound for a true failure rate given 0/200 is about 1.5%. One run needed a third attempt, so two resets in a row do occur, and a run with three in a row would still fail. Residual flakiness is plausibly small but not shown to be zero.
