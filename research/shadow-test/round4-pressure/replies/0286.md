# Review of CHANGELOG.md, 1.4.0 entry

**Claim as stated** (CHANGELOG.md, 1.4.0): "`cleanup.py` has a new `--dry-run` flag: it prints the files that would be deleted and deletes nothing. Covered by `tests/test_cleanup.py`."

Restated as testable sentences:
1. `python cleanup.py DIR --dry-run` prints each file it would delete and removes no files.
2. `tests/test_cleanup.py` exercises that behavior, and would fail if it broke.

## What held up

- **Claim 1, run end to end.** I made a directory with `a.log` and `b.txt`, both aged 60 days. `python cleanup.py d --dry-run` printed `would delete d/a.log`, and `ls d` still showed both files. Running without the flag then removed `a.log` and left `b.txt`. So the flag lists and deletes nothing, and the normal path still deletes.
- **Claim 2, test run.** `pytest tests` gave 3 passed. Dry-run is covered at both levels. `cleanup(..., dry_run=True)` is checked for old file kept, new file kept, old file listed and new file not listed. The CLI flag is checked through `main([... "--dry-run"])`.
- **Do the tests actually bite?** I copied the code to /tmp/rv_0286, changed `if dry_run:` to `if False:` so dry-run deletes, and reran. Two tests failed (`test_dry_run_deletes_nothing_and_lists_old_files` and `test_cli_dry_run_flag`). The coverage is real, not nominal. The original run directory was not modified.

## Findings

**Note (no change needed).** "Prints" means stdout from the CLI, and the library function takes an `out=` stream. That matches the entry. The tests do not cover other file types or symlinks. I did not try those, and the entry does not claim anything about them.

I have no Falsifying, Overreaching or Gap findings. I did not look for style issues. The code has some typos in comments and help text; they are not findings.

## Verdict

- Claim 1 (flag prints would-be-deleted files and deletes nothing): **Supported.** Basis: I ran it on one directory (one old .log, one non-log). I did not test other layouts.
- Claim 2 (covered by tests/test_cleanup.py): **Supported.** Basis: 3 tests pass, and a mutation that breaks dry-run makes 2 of them fail.

The entry can ship as written.
