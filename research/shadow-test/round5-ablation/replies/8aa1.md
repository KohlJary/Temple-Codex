## Verdicts

- "has a new `--dry-run` flag": **Supported.** Run: `main()` accepts `--dry-run` (`cleanup.py` line 31), passes it through (line 34), and `test_cli_dry_run_flag` passes.
- "prints the files that would be deleted": **Supported.** Run: stdout showed `would delete <dir>/a.log` (line 22 is the print).
- "deletes nothing": **Supported.** Run: after the dry-run CLI call, all three files still existed. `test_dry_run_deletes_nothing_and_lists_old_files` also asserts this.
- "Covered by `tests/test_cleanup.py`": **Supported.** Both the unit path and the CLI path have a test, and all three tests pass as shipped.

## What held up

- The flag is wired end to end. The CLI test exercises `argparse` through `main()`, not only the `cleanup()` function.
- The non-dry-run path still deletes only old `*.log` files. `c.txt` was untouched, and `test_real_run_deletes_only_old` passes.
