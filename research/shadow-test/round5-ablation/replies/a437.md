- "Deletes nothing": the `os.remove` call sits in the `else` branch. `test_dry_run_deletes_nothing_and_lists_old_files` and `test_cli_dry_run_flag` both assert the old file still exists afterward.
- "Covered by `tests/test_cleanup.py`": confirmed by the test run above.
