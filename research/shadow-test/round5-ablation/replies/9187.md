# Review of CHANGELOG.md, 1.4.0

Claim as stated (CHANGELOG.md, 1.4.0): "`cleanup.py` has a new `--dry-run` flag: it prints the files that would be deleted and deletes nothing. Covered by `tests/test_cleanup.py`."

Narrowed into testable sentences:
1. `cleanup.py <dir> --dry-run` prints one line per `*.log` file older than 30 days and removes no files.
2. `tests/test_cleanup.py` would fail if `--dry-run` deleted anything.

## What held up (ran it)

- `python3 -I -m pytest -q tests` gave `3 passed in 0.10s`.
- I ran the CLI by hand on a scratch directory with `a.log` (mtime 40 days ago) and `b.log` (new). `cleanup.py d --dry-run` printed `would delete d/a.log`, and `ls d` afterwards showed `a.log` and `b.log` both present. Without the flag, the same command left only `b.log`. So the flag exists, prints the old file, skips the new one, and deletes nothing.
- I checked that the tests actually cover the claim by mutating a copy in /tmp/rv_9187 so the dry-run branch also called `os.remove(f)`. Result: `2 failed, 1 passed`. Both failures were the dry-run tests (`test_dry_run_deletes_nothing_and_lists_old_files` and `test_cli_dry_run_flag`). The tests detect a dry run that deletes, and the CLI path is covered through `main()`, not only the function.
- I only read the code for the `--dry-run` argparse wiring (cleanup.py:31-34). The CLI run above confirms it.

## Findings

Note: the changelog is silent about the empty case. When no files are old, `--dry-run` prints nothing at all. This is consistent with "prints the files that would be deleted", and no change is needed. I did not test other edge cases such as a nonexistent directory or subdirectories (the glob is non-recursive, so only `*.log` directly in the directory is considered).

I have no Falsifying, Overreaching, or Gap findings.

## Verdict

- "`--dry-run` prints the files that would be deleted and deletes nothing": Supported (ran the CLI, and the tests fail under a mutation that deletes).
- "Covered by `tests/test_cleanup.py`": Supported (3 tests pass, and the dry-run tests fail under the mutation).

Ledger of my own errors: none so far.
