# Review of CHANGELOG.md, 1.4.0

Claim as stated (CHANGELOG.md, 1.4.0): "`cleanup.py` has a new `--dry-run` flag: it prints the files that would be deleted and deletes nothing. Covered by `tests/test_cleanup.py`."

Narrowed into testable sentences:
1. `python cleanup.py DIR --dry-run` prints one line per old `*.log` file and removes nothing.
2. `tests/test_cleanup.py` exercises that behavior, so a regression would be caught.

## Findings

None. I found no defect in this entry.

## What held up (all run, on a copy in /tmp/rv_2037; your directory is untouched)

- **Tests pass.** `pytest -q` gives 3 passed.
- **The tests guard the feature.** I mutated the copy (`if dry_run:` changed to `if False:`, so the flag is ignored). 2 of 3 tests failed: `test_dry_run_deletes_nothing_and_lists_old_files` and `test_cli_dry_run_flag`. So "Covered by tests" is true in the strong sense. The tests detect the feature breaking, not merely that they run. I restored the original afterward.
- **CLI end to end.** I made `a.log` and `b.txt`, both 40 days old, and ran `python cleanup.py . --dry-run`. It printed `would delete a.log`, and both files were still present afterward. Running without the flag then deleted `a.log` and left `b.txt`. So the flag changes behavior as described, and the non-dry path still works.
- **Scope of "files".** The tool only considers `*.log` files older than 30 days. `b.txt` was never listed. The changelog says "files that would be deleted", which matches the set it would actually delete, because the dry run and the real run share `find_old`.

## Notes (true, checked, nothing needs to change)

- Dry-run prints paths as built from the directory argument (`a.log` for `.`, the full path for an absolute dir). This is consistent with the claim.
- I did not test unusual cases: symlinks, unreadable directories, a nonexistent `dir`, or a failure partway through deletion. The changelog does not claim anything about them, so this is not a gap in the claim.

## Verdicts

- "New `--dry-run` flag: prints the files that would be deleted and deletes nothing": **Supported.** Confirmed by CLI run and by test run.
- "Covered by `tests/test_cleanup.py`": **Supported.** Confirmed by mutation: the tests fail when the flag is ignored.

The entry is exact as written. Nothing to repair.
