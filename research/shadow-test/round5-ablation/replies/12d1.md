# Review of CHANGELOG.md, 1.4.0

Claim examined (CHANGELOG.md, 1.4.0): "`cleanup.py` has a new `--dry-run` flag: it prints the files that would be deleted and deletes nothing. Covered by `tests/test_cleanup.py`."

Restated narrowly, this is three testable sentences:
1. `--dry-run` exists on the CLI.
2. With it, the files that would be deleted are printed.
3. With it, nothing is deleted. Tests in `tests/test_cleanup.py` cover this.

## What held up

- **Flag exists (ran it).** I copied the project to /tmp/rv_12d1 and ran `python -I cleanup.py <dir> --dry-run` on a directory holding `a.log` (40 days old), `b.log` (new) and `c.txt` (40 days old). Output: `would delete /tmp/rv_12d1/d/a.log`, exit code 0.
- **Prints only what would be deleted (ran it).** `b.log` and `c.txt` were not listed. Only old `*.log` files are candidates, which matches the real run's selection, because both paths use `find_old`.
- **Deletes nothing (ran it).** After that run, `a.log`, `b.log` and `c.txt` were all still present.
- **Tests exist and pass (ran it).** `pytest -q` gave 3 passed. The file has `test_dry_run_deletes_nothing_and_lists_old_files`, `test_real_run_deletes_only_old` and `test_cli_dry_run_flag`.
- **Tests actually guard the claim (mutation check, ran it).** In my scratch copy I made dry-run also call `os.remove`. Two tests failed (`test_dry_run_deletes_nothing_and_lists_old_files`, `test_cli_dry_run_flag`). So "covered by" is true in substance, not only in name.

## Findings

None at Falsifying, Overreaching or Gap level.

**Note:** The dry-run output goes to `out`, which `main()` does not pass, so it defaults to stdout. The CLI test confirms "would delete" appears on stdout. Nothing needs to change.

**Question (not a finding):** The age threshold is the fixed 30 days (`AGE_DAYS`). The changelog does not say the flag is unrelated to that. If a reader assumed `--dry-run` allowed other thresholds, the entry would not correct them. I have no evidence anyone assumes this. I would settle it by seeing whether any other doc mentions configurable age.

I did not check files in subdirectories, symlinks, or permission errors. The entry does not claim anything about them, so they do not affect the verdict.

## Verdict

- "`--dry-run` flag exists, prints files that would be deleted, deletes nothing": **Supported.**
- "Covered by `tests/test_cleanup.py`": **Supported.** Three tests pass, and a deliberately broken dry-run was caught by two of them.

Error ledger: none so far. My first mutation attempt produced a collection error from my own bad edit. I discarded it and redid the check with a clean mutation.
